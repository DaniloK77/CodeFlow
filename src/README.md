# CodeFlow

**CodeFlow** is a modern, fully responsive front-end website template built using **React** and **Tailwind CSS**.  

This project focuses on **UI layout and component design**, teaching the fundamentals of building React components with Tailwind styling.  

> ⚠️ Note: This project is **UI-only**. It does not include backend functionality or dynamic data handling. It's perfect for learning React & Tailwind and experimenting with design patterns.

## Features

- Fully responsive layout (mobile, tablet, desktop)
- Hero section with animated background effects
- Reusable components: Navbar, Footer, Feature sections, Buttons, and Cards
- Code editor style sections using `react-syntax-highlighter`
- Modern UI/UX design principles with Tailwind CSS
- Social media icons with hover effects using `lucide-react`

## Tech Stack

- [React](https://reactjs.org/) – Component-based UI library
- [Tailwind CSS](https://tailwindcss.com/) – Utility-first CSS framework
- [Lucide React](https://lucide.dev/) – Open-source icon library
- [React Syntax Highlighter](https://www.npmjs.com/package/react-syntax-highlighter) – For displaying code snippets
